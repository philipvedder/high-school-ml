From a jump to a smooth step: the sigmoidVom Sprung zur sanften Stufe: die Sigmoidfunktion

$\sigma(z) = \dfrac{1}{1 + e^{-z}}$
  1. Confidence: $\sigma(z)\in(0,1)$ reads like a probability: “73 % orange”.Sicherheit: $\sigma(z)\in(0,1)$ lässt sich wie eine Wahrscheinlichkeit lesen: „73 % orange“.
  2. Smooth: a small change in $w$ gives a small change in $\hat y$. With the step, nothing happens and then suddenly everything does.Glatt: Kleine Änderung von $w$ ergibt kleine Änderung von $\hat y$. Bei der Stufe passiert nichts und dann plötzlich alles.
  3. Differentiable: we will need the derivative for learning (Part IV). The step has derivative 0 everywhere.Differenzierbar: Die Ableitung brauchen wir fürs Lernen (Teil IV). Die Stufe hat überall Ableitung 0.
⬇ deep dive
Point 3 is the most important one for later: gradient descent needs slopes. If the derivative is zero everywhere, the computer gets no hint which direction to change the weights. Move the z slider, toggle the derivative.
deep dive

Properties of the sigmoidEigenschaften der Sigmoidfunktion

$\sigma(0) = \tfrac12$

$\displaystyle\lim_{z\to\infty}\sigma(z) = 1,\qquad \lim_{z\to-\infty}\sigma(z) = 0$

Symmetry:Symmetrie: $\;\sigma(-z) = 1 - \sigma(z)$

Derivative (chain rule):Ableitung (Kettenregel):

$$\sigma'(z) = \frac{e^{-z}}{(1+e^{-z})^2} = \underbrace{\frac{1}{1+e^{-z}}}_{\sigma(z)}\cdot\underbrace{\frac{e^{-z}}{1+e^{-z}}}_{1-\sigma(z)}$$
$\sigma' = \sigma\,(1-\sigma)$

SteepnessSteilheit

$\sigma(k\cdot z)$ becomes steeper for large $k$ and tends to the step function as $k\to\infty$. Large weights therefore mean a “confident” neuron.$\sigma(k\cdot z)$ wird für großes $k$ steiler und strebt für $k\to\infty$ gegen die Stufenfunktion. Große Gewichte bedeuten also ein „selbstsicheres“ Neuron.

The XOR problemDas XOR-Problem

Orange if exactly one of $x_1, x_2$ is 1. Try it: more than 75 % is impossible!Orange, wenn genau eines von $x_1, x_2$ gleich 1 ist. Probiert es: Mehr als 75 % geht nicht!

⬇ deep dive: proof
XOR = "exclusive or". Let students try for a minute. Historical note: Minsky & Papert (1969) pointed out this limitation of single-layer perceptrons, which contributed to the first "AI winter".
deep dive

Proof: no line separates XORBeweis: Keine Gerade trennt XOR

Suppose $w_1, w_2, b$ classify all four corners correctly (orange $\Leftrightarrow z>0$):Angenommen, $w_1, w_2, b$ klassifizieren alle vier Ecken richtig (orange $\Leftrightarrow z>0$):

$(0,0)$ ●: $\quad b \le 0$

$(1,0)$ ●: $\quad w_1 + b > 0$

$(0,1)$ ●: $\quad w_2 + b > 0$

$(1,1)$ ●: $\quad w_1 + w_2 + b \le 0$

Add the middle two:Die mittleren zwei addieren: $\;w_1 + w_2 + 2b > 0$

$\Rightarrow\; w_1+w_2+b > -b \ge 0$

This contradicts the last line.Das widerspricht der letzten Zeile. ↯

So no single neuron can solve XOR. ∎Also kann kein einzelnes Neuron XOR lösen. ∎

“Rectified Linear Unit”: negative values become 0, positive values pass unchanged.„Rectified Linear Unit“: Negative Werte werden 0, positive bleiben unverändert.

ReLU is the activation used in most modern networks. Its derivative is 0 for z<0 and 1 for z>0, which will be easy for backpropagation later.

III · LossFehler

The loss functionDie Verlustfunktion (Loss)

Training data: pairs $(x_i, y_i)$, $i=1,\dots,n$, e.g. point and correct colour (1 = orange, 0 = blue).Trainingsdaten: Paare $(x_i, y_i)$, $i=1,\dots,n$, z. B. Punkt und richtige Farbe (1 = orange, 0 = blau).

Mean squared error:Mittlerer quadratischer Fehler:

$$L(\theta) = \frac1n\sum_{i=1}^{n}\big(\underbrace{f_\theta(x_i)}_{\text{prediction}} - \underbrace{y_i}_{\text{truth}}\big)^2$$
  • $L \ge 0$, and $L = 0$ ⇔ every prediction is perfect$L \ge 0$, und $L = 0$ ⇔ alle Vorhersagen perfekt
  • squaring: big mistakes cost a lot, and the sign doesn’t matterQuadrat: große Fehler kosten viel, das Vorzeichen ist egal

The crucial switch of perspectiveDer entscheidende Perspektivwechsel

The data $(x_i, y_i)$ is fixed. What we can change is $\theta$.Die Daten $(x_i, y_i)$ sind fest. Was wir ändern können, ist $\theta$.

$L:\ \theta \longmapsto L(\theta)$

So the loss is a function of the parameters!Der Loss ist also eine Funktion der Parameter!

Emphasise the switch: in school, x is the variable. Here the data is constant and the parameters are the variables. In practice for classification one often uses cross-entropy instead of squared error (the Lab's station 5 does), but the idea is identical.

IV · BackpropagationBackpropagation

But how do we get $\partial L / \partial w$?Aber wie bekommen wir $\partial L / \partial w$?

A network is a chain of simple functions. The chain rule:Ein Netz ist eine Kette einfacher Funktionen. Die Kettenregel:

$\big(f(g(x))\big)' = f'(g(x))\cdot g'(x)$

Read it as rates of change:Gelesen als Änderungsraten:

$\dfrac{dL}{dw} = \dfrac{dL}{dh}\cdot\dfrac{dh}{dw}$

⚙️ GearsZahnräder

Gear A turns 3× as fast as B, and B 2× as fast as C.
⇒ A turns 3 · 2 = 6× as fast as C.Rad A dreht 3× so schnell wie B, B 2× so schnell wie C.
⇒ A dreht 3 · 2 = 6× so schnell wie C.

Along a chain, rates of change multiply.Entlang einer Kette multiplizieren sich Änderungsraten.

The chain rule is usually taught in 11th grade. If not, the gear analogy suffices: "if I wiggle w a little, how much does L wiggle?"

Both gradients are negative, so increase both weights. And all of this from one backward pass, reusing intermediate results.Beide Gradienten sind negativ, also beide Gewichte vergrößern. Und alles aus einem Rückwärtsdurchlauf, mit wiederverwendeten Zwischenergebnissen.
Click through: forward pass (cyan) computes z = w1·x = 1, h = ReLU(1) = 1, ŷ = w2·h = 1.5, L = (1.5−3)² = 2.25. Backward (orange): dL/dŷ = 2(ŷ−y) = −3. For w2: ŷ = w2·h, so dŷ/dw2 = h = 1, giving dL/dw2 = −3. Going further back: dŷ/dh = w2 = 1.5, so dL/dh = −4.5. ReLU'(1) = 1, so dL/dz = −4.5. Finally z = w1·x, so dz/dw1 = x = 2, giving dL/dw1 = −9. Key point: each node only needs its own local derivative, and the products are passed backwards. That is why it's called back-propagation (Rumelhart, Hinton & Williams 1986).
